# Rainbow Fashions Inventory

Production-ready Phase 1 AI Inventory Management System for a clothing shop.

Stack:

- React + Vite + TypeScript
- Tailwind CSS
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- JWT authentication
- Modular OCR/AI invoice extraction interface
- React Native Expo Android scaffold
- Docker deployment scaffold

Delivered modules:

- Authentication
- Categories
- Brands
- Products and variants
- Invoice upload
- OCR extraction interface
- Purchase review and confirmation
- Stock movement history
- Dashboard
- Product search
- Purchase history
- Role-based route dependencies
- PWA install support
- Deployment and backup scaffolding

Stock is never updated during upload or OCR. Stock changes only after purchase confirmation.
